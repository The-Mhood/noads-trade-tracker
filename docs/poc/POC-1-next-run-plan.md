## Traceable mandatory acceptance and query budget (future run only)

A test **PASS** needs retained timestamped, redacted request/response, broker tickets, read-back, linked history and a reviewer decision; a missing observation is **UNVERIFIED**, not PASS. These bounds are *proposed test-design ceilings*, not evidence of dollar cost, broker finality or approval to execute. Any incident stops placements and consumes the remaining query allowance on reconciliation only; no query budget/time expiry turns UNKNOWN into finality. The current legacy harness does **not** implement this matrix.
